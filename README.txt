リラクゼーション ゆらり｜GitHub Pages 公開用完成パッケージ

【公開方法】
1. このZIPファイルを解凍します。
2. 解凍してできたフォルダの「中身」をすべて、専用リポジトリの一番上の階層へアップロードします。
3. GitHubの Settings → Pages を開きます。
4. Build and deployment の Source を「Deploy from a branch」にします。
5. Branch を「main」、フォルダを「/(root)」にして Save を押します。

【重要】
・ZIPファイル自体をGitHubへアップロードしないでください。
・yurari-github-pagesフォルダごとではなく、その中の index.html、style.css、script.js、save-menu.css、imagesフォルダなどをアップロードしてください。
・imagesフォルダの名前や中の画像名を変更しないでください。

公開後に写真やデザインが崩れた場合は、公開ページのURLと画面の画像を添えてお知らせください。
